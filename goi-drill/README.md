# 統一テスト語彙ドリル

統一テスト対策プリント（入試頻出漢字＋現代文重要語彙TOP2500 四訂版）の問題を、スマホ・PCで練習できる1ファイルのWebアプリ。

| セット | 問題数 | 形式 |
|---|---|---|
| 第2回 読み（P84〜P91） | 100 | カード（めくって○×自己採点） |
| 第2回 書き①（P52〜P75） | 150 | カード |
| 第2回 書き②（P136〜P159） | 150 | カード |
| 第3回 意味 重要語①②（P210〜P219） | 40＋40 | 4択／カード |
| 第3回 カタカナ語（P220〜P231） | 50 | 4択／カード |

## できること
- 出題: **順番通り／ランダム／苦手優先／間違えた問題だけ**。範囲（例 1〜50）と問題数を指定できる
- 記録: 問題ごとに正答率と直近の結果を保存（ブラウザの localStorage。生徒ごとの端末に残る）
- 苦手優先: 直近で×・正答率が低い・未学習・しばらく解いていない問題を優先して出す
- 問題ごとの記録マップ（定着／あやしい／苦手／未学習の色分け）
- 一覧で確認: 答えを隠す「赤シート」表示。タップで1問ずつ答えを確認
- めくった面では、読みは傍線部にふりがな、書きは文中のカタカナを漢字に置き換えて表示
- 縦書き表示の切り替え、手書きメモ欄（書いてからめくる）、教科書ページ番号の表示
- QRコード表示（右上の「QR」）。トップや各セットを直接開くQRを作れ、教室で映せる大きさで表示できる。URL末尾に `#yomi` `#kaki1` などを付けるとそのセットが直接開く
- PC はキーボード操作可（スペース＝めくる、←＝×、→＝○、1〜4＝選択）

## ファイル
- `index.html` … 配布用（データ込みの完全な1ファイル。そのまま公開できる）
- `app.html` … 画面とロジックの本体（`/*DATA*/` にデータが入る）
- `data/questions.json` … 問題データ
- `tools/extract.py` … 対策プリントPDFから問題・解答を抽出
- `tools/fix.py` … 文字化けなどの手修正を当てて `questions.json` を作る
- `tools/build.py` … `app.html` ＋データ → `index.html`

## 次回のプリントで作り直すとき
```bash
pip install pymupdf
python3 tools/extract.py 対策プリント.pdf /tmp/raw.json   # ページ範囲は extract.py 末尾の表を調整
python3 tools/fix.py /tmp/raw.json data/questions.json    # セット名・範囲は fix.py の META を調整
python3 tools/build.py                                    # index.html を再生成
```
抽出は PDF の文字と傍線（ベクター線）の位置から行う。フォントの都合で化ける字（今回は「剥」「凋」）があるので、`fix.py` の置換表で直す。

## 公開
`index.html` は外部サーバー不要の静的ファイル。GitHub Pages、Google サイトへの埋め込み、学内サーバーなどにそのまま置ける。
