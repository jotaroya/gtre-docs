## プロジェクト概要

Gトレは、中学生を主な対象とした学習支援プリント配信Webアプリケーションである。数学・英語を中心とした教科別・学年別のPDF教材を、ブラウザ上でプレビュー・印刷できる環境を提供する。

### 主な機能

- **教科・学年・単元の階層ナビゲーション** — トップページから教科→学年→出版社→単元の順で素早くアクセス
- **複数オプション選択・PDF結合** — 本編・テスト・解答など複数のPDFをブラウザ内で結合して一括印刷
- **英語教科書6社対応** — ONE WORLD / BLUE SKY / HERE WE GO! / NEW CROWN / NEW HORIZON / SUNSHINE（中1〜中3）
- **スマートフォン対応** — ボトムタブナビによるモバイルフレンドリーな3カラムレイアウト
- **その他教材のセルフ登録** — パスワード認証付きで教材・単元をDB永続化
- **将来計画: 英語単語オプションのJSON管理** — 本文単語・予習単語・復習単語等をサブオプションとして個別選択・1ページ結合印刷

### 技術スタック

| レイヤー | 技術 |
|---------|------|
| フロントエンド | React 19 + TypeScript + Tailwind CSS v4 |
| バックエンド | Express 4 + tRPC 11 |
| データベース | MySQL（TiDB互換）+ Drizzle ORM |
| PDF処理 | pdf-lib（ブラウザ内結合） |
| ファイルストレージ | S3互換ストレージ + CloudFront CDN |

## スクリーンショット

### トップページ
教科カテゴリカード（英語・数学・その他）と学年ボタンを表示。背景に文房具写真を使用したヒーローエリア付き。

### 教材ページ（3カラムレイアウト）
- **左カラム:** 章・単元アコーディオンリスト
- **中央カラム:** PDFプレビュー（iframe + BlobURL）
- **右カラム:** オプション選択・印刷設定

### その他教材
教材一覧・新規登録フォーム・単元追加モーダル（PDFアップロード付き）

## ローカル開発

```bash
# 依存関係のインストール
pnpm install

# 開発サーバーの起動
pnpm dev

# DBマイグレーション
pnpm db:push

# テスト実行
pnpm test

# 型チェック
pnpm check
```
